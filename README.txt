免费发布建议：GitHub Pages
1. 登录 https://github.com/ 并注册/登录账号。
2. 新建一个公开仓库，例如 watch-catalog。
3. 上传 index.html 到仓库根目录。
4. 打开仓库 Settings → Pages。
5. 在 Build and deployment 中选择 Deploy from a branch。
6. Branch 选择 main，目录选择 /(root)，保存。
7. 等待 GitHub Pages 发布完成，页面会显示公开网址，通常为 https://你的用户名.github.io/watch-catalog/。
8. 用手机网络打开网址，测试中英切换、分类按钮和每个 WhatsApp 按钮。

说明：
- GitHub Pages 可免费托管静态 HTML 网站；公开仓库内容会公开可见。
- 这是展示目录，不包含购物车、在线支付、库存管理或订单后台。
- WhatsApp 链接按国际格式生成；发布前请用自己的手机测试该号码是否能打开对应 WhatsApp 账号。
- 若 GitHub Pages 页面不能立即访问，检查仓库 Pages 设置和部署状态。
