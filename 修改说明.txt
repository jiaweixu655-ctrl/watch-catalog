手表目录网站：以后简单修改商品资料

文件说明：
- index.html：网页设计文件，通常不需要修改。
- products.json：商品资料。以后改价格、名称、型号、分类，主要修改这个文件。
- images/watch-001.jpg：第 001 号手表图片。

常见修改示例（打开 products.json）：
1. 改价格：找到对应商品的 "price": 250，把 250 改成数字价格，例如 280。
2. 改英文名：修改 "name_en" 后面的文字。
3. 改中文名：修改 "name_zh" 后面的文字。
4. 改型号：修改 "model" 后面的文字。
5. 换图片：上传新图片到 images 文件夹，并把该商品的 "image" 改为 "images/新图片文件名.jpg"。
6. 新增商品：复制一个完整的商品对象，粘贴到列表末尾，注意对象之间用逗号分隔，并使用不同的 id。

重要：
- products.json 是严格格式，双引号、逗号都要保留；价格写数字，不要写成 "US$250"。
- 在 GitHub 仓库根目录上传/替换 index.html 和 products.json，并保留 images/watch-001.jpg。初次安装时三项都需要存在。
- 以后只改商品信息时，通常只需上传/替换 products.json；图片有变更时才需要同时上传图片。
- 每次在 GitHub 点击 Commit changes 后，等待约 1–5 分钟刷新网站。
- 网站仍然使用 GitHub Pages，不需要单独服务器。
